# 屏后 · 顾闳中的一夜

一支烛，一间散了席的屋子。

烛照到哪里，哪里才被记住；你把烛移开，余痕慢慢褪去。
五段屋子——**听乐、观舞、歇息、清吹、散宴**——每一段留下的是刚被用过的器物：
还倚着的琵琶、还支着的鼓、盆里没静的水、席上并排的笛、倒扣的杯。

画里没有一张脸，也没有一个人。顾闳中奉命去韩熙载家"目识心记"，
回来画给李煜看；他坐在屏风后面，看见的就是这些。

  只以原画的段落、器物与构图关系为依据，全部由代码在 Canvas 上重绘。

## 怎么看

打开就能用，不需要登录、不联网、不加载任何外部素材。

| 操作 | 作用 |
| --- | --- |
| 移动指针 / 拖动手指 | 横着走：走过五段屋子；竖着抬：把烛举高或放低 |
| 停住 1.2 秒 | 题记浮出来（「一 · 听乐」与一句） |
| ← → ↑ ↓ | 键盘也能举烛 |
| 系统开启「减少动态效果」 | 烛火与镜头不再抖，画面照常 |

手机上用手指走，页面不会跟着滚。

## 跑起来

```bash
npm ci
npm run dev        # 开发
npm run build      # 构建到 dist/
npm run verify     # 一条命令跑完：类型、单测、构建、e2e、界面量测、卫生检查
```

`npm run verify` 是交件的硬门槛：它在全新 clone 上退出 0，才说明这份东西在别人机器上也成立。

## 里面是什么

```
src/
  main.ts       启动、循环、输入（指针 / 触摸 / 键盘）、DOM 覆层同步
  state.ts      纯状态机：镜头、烛心、五段、题记门槛、余痕衰减（单测全在这上面）
  scene.ts      五段屋子的构图
  props.ts      器物：屏风、榻、案、席、烛台、鼓、琵琶、盆、笛、扇、香炉、杯、卷轴、瓶
  light.ts      光：软边光斑、暖光、余痕层（取最大值而不是相加）、压暗
  palette.ts    墨烛配色
  rng.ts        可复现随机与噪声
test/           单测（状态机、可复现、无素材、无外链）
scripts/        verify / e2e / measure-ui / shot / serve / 字体子集
docs/           SPEC、UI 与尺子、AI 使用记录、素材来源、提交文案
proof/          截图、界面量测报告、闸 D 的盲排记录
```

## 三条硬规矩

1. **运行时不联网**：除同源静态资源外零请求，评委会在什么网络环境下打开都一样。
2. **没有一个位图**：全部图形由 Canvas 绘制；字体是随包的思源宋体子集（OFL）。
3. **可复现**：同一个随机种子画出同一间屋子。
