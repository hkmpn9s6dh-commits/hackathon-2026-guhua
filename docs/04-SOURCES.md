# 04 · 素材来源与许可

比赛规则原文（潮新闻 2026-08-21 通稿）：
> 「素材来源仅限官方文博开放资源、标注公有领域或 CC0 许可的公开资源；使用第三方素材需取得覆盖赛事改编、展映宣传的完整书面授权。」

## 一、作品依据的原画

| 项 | 内容 |
| --- | --- |
| 作品 | 《韩熙载夜宴图》卷 |
| 传为 | 五代 顾闳中 |
| 收藏 | 故宫博物院 |
| 版权状态 | **公有领域**（作者逝世逾千年；作品本身为古代文物） |
| 我们用了什么 | **只用了"画了什么、分几段、器物怎么摆"这些事实**：五段（听乐/观舞/歇息/清吹/散宴）、屏风与床榻分隔场景、琵琶、鼓、盆、笛、烛、香炉、席案 |
| 我们没用的是什么 | **没有使用任何扫描件像素**：仓库里不存在任何位图（`verify.sh` 的 hygiene 段会拒绝 png/jpg/webp）；画面全部由 `src/props.ts` 与 `src/scene.ts` 用 Canvas 2D 重绘 |

这样做的两个理由：一是版权上最干净；二是这件作品的立场就是"重画一遍，而不是贴一张图"。

## 四、没说清的地方（如实列出）

1. **70 分与 30 分的细分项没有公示**。本作按通用维度自设验收条件，不假装那是官方细则。
2. **9 位评委名单没有公示**。
3. **提交入口**：公开信息只说"关注官网与官方公众号"，另有"在抖音上传作品并带 #2026古画AI新生计划 #M511光影汇"。
   本作按"作品页 + 演示视频 + 创作说明"准备，具体提交动作请用户按官方入口完成。
4. **"AI 转绘"的边界**：规则鼓励使用 AI，未强制。本作的取舍写在 `docs/03-AI.md`。
