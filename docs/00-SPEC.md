## 二、作品一句话

**《屏后》**：一支烛，看一卷夜宴——烛照到哪里，哪里才亮；停得越久，那处留得越久；
你把烛移开，余痕慢慢褪去。**顾闳中当年只有烛照到的地方记得住，你现在也一样。**

## 三、为什么是《韩熙载夜宴图》

1. 它本来就是一次**窥视**的产物：顾闳中奉命去韩熙载家「目识心记」，回来画给李煜看。
   观者在这幅画里的位置，从一千年前起就是「躲在屏风后面的人」。
2. 它是**五段连续叙事**（听乐 / 观舞 / 歇息 / 清吹 / 散宴），段与段之间用屏风与床榻隔开——
   天然的五个场景，天然的空间分割，不需要我们另造结构。
3. 它画的是**夜**。全卷的光源是烛。把「光」做成交互的唯一变量，是这幅画自己给的题解。
4. 公有领域：故宫博物院藏，五代顾闳中（传），作者逝世逾千年，属公有领域；
   本作不使用任何扫描件像素，只以原画的构图、人物位置、器物形制为依据程序化重绘（见 §6）。

## 五、验收条件（可判定）

- **AC-1** 全新 clone，`bash scripts/verify.sh` 退出 0。
- **AC-2** 首屏 3 秒内出现可交互画面（`performance` 首帧 < 3000 ms，本地 static build）。
- **AC-3** 指针横向移动 → 镜头随之推进（单调不减），光斑保持在视口中央（两端除外）；纵向跟手，夹在 20%–88% 之间。
- **AC-4** 五段全部可达：指针在屏幕横向 0/25/50/75/100% 处停留，分别命中第 1–5 段（`data-section` 断言）。
- **AC-5** 题记门槛：光斑中心在某段热区内连续 ≥ 1200 ms 才出现；< 800 ms 不出现（单测 + e2e 各一条）。
- **AC-6** 余痕：干净页面上，照过之后该点的余痕亮度显著高于未照时；光离开后按 12.5%/秒衰减，10 秒后低于峰值三成（单测 `memoryLevel(10) < 0.3` + e2e 像素采样各一条）。
- **AC-7** 无网络：运行期除同源静态资源外零请求（e2e 断言 request 列表）。
- **AC-8** 移动端：375×812 下可交互，光斑半径随短边缩放，触控不触发页面滚动（`touch-action: none`）。
- **AC-9** 可访问：`prefers-reduced-motion` 下停止烛火抖动与镜头缓动；键盘 ←/→ 可移动烛光；`aria-live` 播报当前段名。
- **AC-10** 字体随包：构建产物含 woff2，中文字形不走系统字体（截图比对无 fallback）。
- **AC-11** 界面卫生：`node scripts/measure-ui.mjs` 退出 0（正文最小字号、暗部对比度、标题不溢出、触控目标）。
- **AC-12** 素材可核：`docs/04-SOURCES.md` 写明「五张场景图由生图模型生成、不使用扫描件像素」；
  仓库里只有五张 `scene-*.webp` 与一份字体，没有别的媒体文件（单测与 `verify.sh` 都卡这一条）。
- **AC-13** AI 使用可核：`docs/03-AI.md` 列出每次 AI 生成（工具、提示词、产物、用途），产物随包并带 sha256。
- **AC-14** 复现：同一 seed 下场景几何哈希一致（单测）。
- **AC-15** 提交包五件：线上链接、仓库、创作说明、封面 1500×1000、演示视频（无声版）。

## 六、实现边界（过了闸 A 只删不加）

**做**：五张 AI 生成的工笔场景（每段一张，随包 webp）＋ Canvas 合成：烛光软边遮罩与呼吸环、
余痕记忆层（取照到过的最亮值再衰减）、横向五段长卷与镜头跟随、题记浮现、竖排标题与朱印、移动端与键盘、reduced-motion。

**不做**：
- 不用原画扫描件像素（版权与「重绘」立场），不画完整人物、不描摹面部；
- 不调用任何联网模型（本机 Google/OpenAI 系接口实测 000，无 key）；
- 不做 8K 巨幕 M511 专项（需线下展演环境，另设专项）；
- 不做音频（无授权音源，且静默更贴题）；
- 不复用《朝元》的卷轴/呼吸机制（那是山水与炁，这是室内与烛）。

## 七、与《朝元》的差异（防止自我重复）

| | 《朝元》（赛道 M） | 《屏后》（赛道 N） |
| --- | --- | --- |
| 空间 | 垂直卷轴，山在水中 | 水平长卷，室内五段 |
| 动词 | 按住吸气 / 松手呼气 | 举烛移动 / 停住看 |
| 光 | 天色与云 | 唯一光源是观众手里的烛 |
| 主体 | 山、云、一个人 | 一屋子器物，人都在光外 |
| 记忆 | 无 | 有：余痕会留、会褪 |
