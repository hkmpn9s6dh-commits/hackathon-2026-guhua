# 07 · UI —《屏后》

闸 A 要求的前四节：风格预设、尺子、一个记忆点、主屏规格。后几节是实现记录。

## 1. 风格预设：墨烛（ink-candle）

一句话：**一间没开灯的屋子，只有你手里那支烛。**

| 项 | 取值 |
| --- | --- |
| 主色 | 墨黑 `#0a0908`、绢褐 `#2a211a`、烛金 `#e8b465` |
| 强调色 | 朱砂 `#a8331f`（只用于印与当前段标记，全屏不超过 0.5% 面积） |
| 辅助色 | 石青 `#2f5d6b`（只出现在衣料与器物的一次高光里） |
| 字体 | 思源宋体（Noto Serif SC）子集，随包 woff2；标题竖排 |
| 笔法 | 形体靠明暗边缘成形，不描粗边；墨线最细 1px，只在受光侧出现 |
| 光 | 唯一光源是观众手里的烛；半径约短边 30%，边缘 3 段衰减，中心偏暖 |
| 质感 | 绢底：细密纤维噪点 + 四角压暗；不做纸质贴图、不做投影阴影 |

**三条禁令**：不加渐变霓虹；不加粒子特效雨；不在画面上压大面积毛玻璃面板。
（这三样是「AI 作品」最容易被一眼看穿的三个套路。）

## 2. 尺子（每件写明学哪一点）

| # | 作品 | 类型 | 学哪一点 |
| --- | --- | --- | --- |
| R1 | 《清明上河图3.0》故宫博物院 × 凤凰卫视（2018） | 巨幕沉浸 + 互动长卷（获奖/标杆案例） | 长卷不是「一张图左右拖」，而是一条**动线**：观众的位移本身构成叙事节奏 |
| R2 | 《画游千里江山》故宫沉浸艺术展（2022） | 光影沉浸空间 | 暗场里的**单一色相层次**：只用青绿也能分出远近，暗部不许发灰发脏 |
| R3 | teamLab《Drawing on the Water Surface》/ 无界 | 沉浸互动（国际获奖） | 光就是造型：形体靠**明暗边缘**成立，不靠描边；观众动作直接改变画面 |
| R4 | 故宫出版社《韩熙载夜宴图》App（2019） | 古画数字解读 | 五段的**切换点**在屏风与床榻，不在时间轴；段落之间要有「隔」 |
| R5 | 敦煌研究院「数字敦煌」/ 云游敦煌 | 文博数字化（获奖） | 绢帛质感靠**纤维噪声 + 不均匀吸光**，不靠贴图；放大看不糊 |
| R6 | Playdead《INSIDE》（2016，多个年度最佳） | 游戏（社区标杆） | 低照度下**剪影的可读性**：一个背影也能读出身份与情绪 |

**反向尺子（明确不学）**：AI 生成图拼贴式的「古画活化」——把原画裁几块、加点粒子、配个古风 BGM。
本次一件都不用。

## 3. 一个记忆点

**你手里的烛照到哪里，哪里才被记住；你移开，余痕慢慢褪去。**
（首屏把这句话写成一行 15px 的字放在左下：一间散了席的屋子，你举着烛。）

- 它同时是交互（移动 = 照亮）、叙事（顾闳中「目识心记」）、和技术（余痕层）。
- 一句话能说清，看一眼能看懂，动一下能感到。
- 取舍：全片只保留这一个机制，不再叠加「点击查看文物详情」这类功能。

## 4. 主屏规格

基准视口 1440×900（桌面）/ 375×812（手机竖屏）。长卷总宽 = 5 × 视口宽。

| 元素 | 位置 | 尺寸 | 备注 |
| --- | --- | --- | --- |
| 画面 | 全屏 | 100% | Canvas，DPR 上限 2 |
| 竖排标题「屏后」 | 右缘内 72px，上缘下 96px | 44px / 行距 1.15 | `writing-mode: vertical-rl`，字距 0.12em |
| 副题「顾闳中的一夜」 | 标题左侧 18px | 15px | 竖排，色 `#8a7a68` |
| 朱印「目识」 | 标题下 28px，右侧 84px | 44×44px | 程序化绘制，朱砂，轻微不齐边 |
| 段名（题记第一行） | 底部上 132px，左 8% | 20px | 「一 · 听乐」 |
| 题记（第二行） | 段名下 10px | 17px | 一句，≤ 18 字 |
| 进度刻度 | 底部上 64px，左 8%–右 8% | 高 1px + 5 个 5px 点 | 当前段点变朱砂，其余 `#3a2f26` |
| 操作提示 | 视口下方 15.5vh 居中 | 18px 胶囊（描边 1px + 深底） | 「移动指针 · 举烛照看」，首次交互后淡出 |
| 首屏一句 | 左下 8vw | 15px | 「一间散了席的屋子，你举着烛」 |
| 出处 | 右下 24px | 12px | 「顾闳中（传）· 韩熙载夜宴图 · 五代」 |

**排版规矩**：正文（题记、提示、出处）一律 ≥ 12px；题记 ≤ 18 字不换行；
中文不用 letter-spacing 撑宽（标题除外）；数字与英文用同一套衬线，不混无衬线。

**量测门槛**（`scripts/measure-ui.mjs`）：标题、题记、提示、出处四类文字的字号与对比度；
触控目标 ≥ 24px；首屏文字总覆盖面积 ≤ 12%。
