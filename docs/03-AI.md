# 03 · AI 使用记录

这份记录回答一个问题：**这件东西里，AI 到底做了什么、人做了什么。**

## 一、结论先说

- **运行时不含任何模型调用**：网页不联网、不加载模型权重、不向任何服务发请求（e2e 断言 request 列表，AC-7）。
- **五张场景图是 AI 生成的**，随包带走（`src/assets/scene-1..5.webp`，共约 0.9 MB），提示词逐条列在下面。
- **不使用任何扫描件像素**：原画只作为构图与器物形制的依据，画面是新画的。
- **代码、测试、文案**由 WorkBuddy（CodeBuddy 内核）里的 AI 助手在人的指令下写成；人负责定方向、选赛、验收、改稿与拍板。

## 一之二、五张场景图（生图记录）

工具：WorkBuddy 内置生图（ImageGen），quality=high，size=1536×1024。
用量：**5 张，约 25–50 credits**（每张 5–10 credits）。

统一风格段（五条提示词共用）：
> 中国五代工笔重彩绢本绘画，夜宴内景，深色夜间室内只有几支蜡烛照明。…色调：墨黑、绢褐、石青、朱砂，
> 烛光暖黄，暗部极深但结构清晰。笔法：铁线描勾衣纹，矿物颜料平涂，绢面细密纹理。横向构图。
> 不要任何文字、印章、水印。

| 段 | 提示词里区别于其它四段的部分 |
| --- | --- |
| 一 · 听乐 | 矮榻上两位士人（背影与侧背影），一名女子抱琵琶侧坐弹奏，背后六扇山水屏风，案上香炉、酒器、烛台 |
| 二 · 观舞 | 中间女子旋身起舞长袖展开，右侧士人坐于鼓前举槌，左侧两位宾客坐于席上观看 |
| 三 · 暂歇 | 士人坐于榻上伸双手在铜盆中洗手，侍女捧盆侧立，榻上两位女子，屏风后透出暖光 |
| 四 · 清吹 | 五位女子并排坐着吹笛与筚篥，右侧士人解衣盘坐持团扇 |
| 五 · 散宴 | 席位已空，倒扣的酒杯、叠起的坐褥、合上的团扇，右侧士人持鼓槌站立送客，两支快烧完的烛 |

后期（`scripts/prepare-art.mjs`，可复跑）：

1. 等比铺满 1600×1067，转 webp（quality 0.86），单张 130–280 KB；
2. **右下角的生成水印**用一圈同色暗角盖掉（那一带本来就是地面）；
3. 产物进 `src/assets/`，跟包走，不联网。

被否掉的两版：① 纯程序化绘制（工笔人物画成了"披风帐篷"，用户判"丑、看不懂、过于抽象"）；
② 用博物馆扫描件（故宫名画记的图被 COS 签名墙挡住，只能拿到 750px 缩略图，不够用）。

这不是省事，是取舍：这件作品的机制是「照到哪里才亮、离开就褪」——
生成式模型给不了这种因果，它只能给一张静态的好看。我们宁可要一个能动的因果。

## 二、工作流（可核）

| 环节 | 谁做 | 说明 |
| --- | --- | --- |
| 选赛、资格核查、条款判断 | 人（张一）定，AI 查证并留痕 | 赛事公告原文与截止时间抓在 `docs/04-SOURCES.md` |
| 作品立意（散宴之后的屋子、烛与记忆） | 人定方向，AI 出候选并自查是否与《朝元》重复 | 差异表见 `docs/00-SPEC.md` §7 |
| 场景图（五张工笔夜宴） | AI 生图，人定画面与取舍 | 提示词与用量见上一节；产物随包 |
| 代码（状态机、合成、光照、余痕） | AI 写，人验收 | 27 单测 + 19 项 e2e + 15 项界面量测，`npm run verify` |
| 视觉判断（第一眼） | **不看 AI 的自评**，交外部模型盲排 | 三轮记录与评委原话在 `proof/gate-d/README.md` |
| 文案（题记五行、说明、提交表） | AI 起草，人改 | 题记全部 ≤ 18 字，单测卡住 |

## 三、用到的工具

- **WorkBuddy（CodeBuddy 内核）+ multica-cb 技能**：主控与施工同一台机器，同一会话。
- 模型：`BC-DeepSeek-V4.1-Flash-1017`（中档）。主控自己的六维打分**不计入**闸 D，闸 D 只看外部盲排。
- 盲排评委：三个互不通气的子代理（文博策展人 / 视觉设计总监 / 普通观众三种提示），只看图、不知道哪张是我们的。

## 四、被否掉的 AI 用法

| 想法 | 为什么没做 |
| --- | --- |
| 用生图模型出「工笔人物」立绘（第一版） | 第一版全程序化，人物读成"披风帐篷"，用户判"丑、看不懂"；改成生图后一眼能读 |
| 用生图做绢本纹理贴图 | 叠上去像雾，把暗部糊成灰；改成纯色 + 接触阴影 |
| 让模型在线生成题记 | 运行时不联网；且题记要能背下来，不能每次不一样 |
