## 3. 作品简介（约 300 字，可整段粘贴）

《屏后》把《韩熙载夜宴图》的五段——听乐、观舞、歇息、清吹、散宴——还原成一间只有烛光的屋子。
观众手里那一点光，就是画面里唯一的灯：照到哪里，哪里才显形；停住一秒多，题记才浮出来；把烛移开，
照过的地方会留下一层淡淡的余痕，几秒之后褪尽。

画面里没有一张脸，也没有一个人。留下的只是刚被用过的器物：还倚在榻边的琵琶、还支着的鼓、
盆里没静的水、席上并排的笛、倒扣的杯。顾闳中当年奉命去韩家"目识心记"，回来画给李煜看；
他坐在屏风后面，看见的正是这些。

技术上，它是一件"用手感讲因果"的网页作品：全部图形由代码在 Canvas 上实时重绘，没有任何位图；
镜头随烛火横向移动（走段）、纵向抬起（举烛），余痕层记录"照到过的最亮值"并按时间衰减。
不联网、不加载外部素材，手机上用手指走，页面不会跟着滚。

## 4. 创作说明（评委看的版本，约 600 字）

**为什么是这一夜。**《韩熙载夜宴图》本来是一次窥视的产物：顾闳中并不是宾客，他是被派去看的人。
画里每一次"屏风隔开两个场景"的转折，都是他的视角在移动。于是我们不给观众一个"看画"的位置，
给一个"躲在屏风后面举着烛"的位置——这既是最古的观看方式，也是最当代的沉浸方式。

**为什么画里没有人。**试过画人：画到第三个版本，人物读起来像披着斗篷的影子。后来想明白：
顾闳中记住的不是脸，是位置和器物；而"人都在光外"恰恰是窥视的真实体验。于是整幅不出现完整的人，
只留下他们刚离开的证据。这个决定同时解决了三件事：视觉上不再有"劣质人物"的风险；叙事上更贴原画
（五段之间的分隔本来就是屏风与床榻，不是人）；机制上更纯（光只照物件，物件不躲光）。

**为什么是"记忆"而不是"点亮"。**单纯的手电筒照亮只是一次性效果，看过就完。所以余痕层记录的不是
"当前有多亮"，而是"照到过的最亮值"，再按 12.5%/秒衰减：照得越久，留得越久；走开十秒，只剩三成。
这一条把"目识心记"从一个说法变成了可以玩的动作——观众会自己发现"我多停一会儿，它就多留一会儿"。

**为什么不用生图。**这件作品的因果是"照到哪里才亮"，生成式模型给不了这个因果，它只能给一张静态的好看。
所以全部图形都是代码画的：屏风的八扇、屏面上的远山、琵琶的四弦、鼓面、盆架、地砖、帷幔的褶，
以及烛火的抖动（一维噪声）与接触阴影。随机种子固定，同一个种子画出同一间屋子。

**技术上的三个决定。**① 运行时不联网：除了同源静态资源零请求，评委会在什么网络环境下打开都一样；
② 状态机与绘制分离：镜头、烛心、五段、题记门槛、余痕衰减都是纯函数，26 条单测直接压在它们上面；
③ 一切可复验：`npm run verify` 在全新 clone 上跑类型、单测、构建、19 项真浏览器 e2e、15 项界面量测，
任何一项不过就不算完。
