# 闸 D：第一眼（盲排记录）

## 做法

把我们自己的首屏和五件同类作品的整屏图混在一起，随机字母命名（A–F），
交给没参与创作的模型各自排序。判据（AME-1134 规则 2）：**每一位评委都把它排在至少 3 件尺子之上**才算过线。

- 尺子（全部 2026-11-14 现场抓取 1440×900 整屏图，只存 `.tmp/gate-d/`，不进仓库）：
  1. 故宫名画记 https://minghuaji.dpm.org.cn/
  2. 数字敦煌 https://www.e-dunhuang.com/
  3. 故宫数字文物库 https://digicol.dpm.org.cn/
  4. teamLab（中文站）https://www.teamlab.art/zh-hans/
  5. 故宫藏品页·王希孟《千里江山图》 https://www.dpm.org.cn/collection/paint/228354.html
- 本轮字母对应（`.tmp/gate-d/key.json`）：A teamLab｜B 数字敦煌｜C 故宫藏品页｜D 故宫数字文物库｜E 故宫名画记｜F **屏后（我们的）**

## 评委原话（第三轮）

**文博策展人**：
> 「F 这一格，看得出，但全靠一行字撑着，画面本身没帮上忙。」
> 「把这行提示字抹掉，它和一张加载失败的空白页无法区分。它不是'看得出可以动手'，是'被告知可以动手'。」

**普通观众**：
> 「全黑里一条细金线、右上'屏后'两字，'移动指针'这句提示诱使人想伸手去试。」（进前三）
> 但仍：「整屏近全黑……要不是那句提示，我会以为页面挂了。」

## 结论：**未过线**（按规则停手，交用户定）

第 3 轮是第二次改做法。规则写明「同一道题改做法两轮还没过，停下來交用户定」，所以这里停。

**我看到的原因**（不是找台阶，是给下一步做判断用）：

1. 这是一张**对照的错位**：五件尺子里四件是「满幅图像」的门户/藏品页，在 720×450 的拼图里天然占便宜；
   我们是一件**暗场交互作品**，它的第一眼要靠"黑 + 一点光 + 一句人话"成立，在缩略图里必然吃亏。
2. 但评委第二条意见是实的：**画面本身没有给出"可以动手"的证据**。目前全靠一行字，这不叫设计，叫标注。
3. 第三条也是实的：未照亮处太平，容易被读成"没加载出来"。抬到 0.2 之后好了一档，但还没到"一眼是屋子"。

## 三条可选路由（请用户定一条）

| 路由 | 做法 | 代价 | 过线概率 |
| --- | --- | --- | --- |
| **A 换尺子** | 尺子换成「暗场 / 单光源 / 交互叙事」同类（如 Kedgwick、Alan Wake 类网站、沉浸戏剧官网、teamLab 单体作品页），不再和"满幅古画门户"比第一眼 | 半天；要被用户认可"尺子换得合理" | 高 |
| **B 换首屏** | 首屏改成"开场即满"：一进来光斑就大、照见琵琶与屏风，并有 0.8 秒的推近；把"可动手"做成画面里有东西在动（烛火、烟、水光） | 半天到一天；会牺牲一点"全黑进门"的气质 | 中 |
| **C 照现状交** | 承认它是"慢热型"作品，靠演示视频与文案把评委带进来 | 0；但闸 D 的规则意义上没过线 | 低—中 |

我的建议：**A + B 的最小组合**——先换尺子重排一次（如果换到暗场同类，我们大概率进前三），
再把"有东西在动"这一条补进首屏（成本低、不损气质）。但这已经超出"改两轮"的额度，等你点头再动。
